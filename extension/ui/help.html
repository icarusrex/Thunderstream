Keyboard reference

This preview assigns no default shortcuts. Open the palette with its toolbar button, or choose a free chord in Manage Extension Shortcuts. Cmd+K is native Search; Cmd/Ctrl+Shift+Enter is native Send Later.

Single-key triage is opt-in and requires a verified UI companion. It is unavailable in this foundation preview.

KeyPlanned action
J / KNext / previous displayed message
EArchive
R / A / FReply / reply all / forward
LThunderbird tag picker
S / U / #Star / unread / move to Trash
CCompose

Send & Archive is an explicit compose action. It archives the original message after confirmed immediate sending. Ordinary Send is unchanged.

Quick Open

Type a folder name or part of its path in the palette. Results show the account and mark the current account. Type favorite or favourite to find existing native Favorites. Manage Favorites using the native folder menu. Enter opens the folder in the original mail tab; Escape closes the palette. Missing or renamed destinations fail safely. Native folder-pane modes remain under your control.
