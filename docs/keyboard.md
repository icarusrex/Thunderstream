# Keyboard

This preview assigns **no default modifier shortcuts**. Use the Thunderbird toolbar actions or assign a free chord in Tools → Add-ons → Manage Extension Shortcuts. Existing installations may retain earlier assignments: clear Thunderstream's Cmd/Ctrl+K, Ctrl+Shift+K and Cmd/Ctrl+Shift+Enter assignments there. Removing manifest defaults does not prove that Thunderbird removes a user's existing shortcut configuration.

Cmd/Ctrl+K belongs to native global search. Ctrl+Shift+K belongs to native Quick Filter. Cmd/Ctrl+Shift+Enter belongs to native Send Later. Thunderstream must not claim these chords.

Within the palette: type to filter, arrows select available commands, Enter executes the selected command, Escape closes. The input exposes its active option using ARIA. VoiceOver verification is pending.

Planned native single keys: J/K next/previous, E archive, R reply, A reply-all, F forward, L Thunderbird tags, S star selection, # Trash, U unread, C compose. They are inactive. UK Mac Alt-produced # is allowed by the dormant guard; no native profile is enabled.
